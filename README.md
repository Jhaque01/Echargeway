# eChargeWay

eChargeWay is a smart EV charging network web application built with React, Vite, Tailwind CSS, Shadcn UI, Leaflet for maps, and Supabase for backend authentication and database.

## Features
- Real-time live charging status
- Find nearby EV charging stations
- See available chargers
- Authentication and User Profiles
- Responsive design for mobile and desktop

## Tech Stack
- Frontend: React 18, Vite, TypeScript
- Styling: Tailwind CSS, Shadcn UI, Framer Motion
- Maps: Leaflet
- Backend: Supabase (Auth, Database)
- State Management: React Query
- Testing: Vitest

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables by copying `.env.example` to `.env` (if applicable) and populating Supabase credentials.
4. Run the development server:
   ```bash
   npm run dev
   ```

## Scripts
- `npm run dev`: Starts the local development server.
- `npm run build`: Builds the app for production.
- `npm run test`: Runs the test suite.
- `npm run lint`: Lints the code.
